# Steps to generate SSO Access Token

1. Go to https://sso.iitb.ac.in/settings
2. Click on "Access Tokens" -> "Configure"
3. Fill LDAP ID and LDAP Password.
4. Click on "Generate new"
5. Select "CC-IITB Email-Service"
6. Copy the Access Token generated "123xxxxxxxxxxxxxxxxxxxxxxxxxxx44" to the "private/.env" -> "IITB_IMAP_ACCESS_TOKEN="
